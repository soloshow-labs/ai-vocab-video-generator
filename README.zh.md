# AI Vocab Video Generator

[English](README.md) | 中文

根据主题生成词表，或直接编辑单词列表，再制作成带朗读的英语单词学习视频。本地
Streamlit 界面支持简体中文和 English，默认使用简体中文；布局、素材、字体、
进度条和朗读方式均可自定义。

项目由 [SoloShow Labs（一人独角show）](https://github.com/soloshow-labs) 维护。

微信公众号：一人独角show

## 功能概览

- 既可以根据主题生成词表，也可以直接编辑按中文、英文分行填写的词表。
- 支持 OpenAI、DeepSeek、Moonshot、Qwen、Ollama，以及自定义的 OpenAI 兼容
  对话接口。
- 每个视频都需要一张本地背景图；单词素材可来自本地文件、Pexels 或 Pixabay。
- 使用 Edge TTS，可分别设置中文、英文快读和英文慢读。
- 支持 9:16 竖屏和 16:9 横屏，可生成问题卡片与答案卡片。
- 每次生成都保存在独立的任务目录中，并记录后续重新生成所需的输入和参数。
- 重新生成时会复用仍然有效的素材、音频和卡片，同时保留之前生成的所有 MP4。
- 可选使用 FunASR/SenseVoiceSmall 将录制的主题语音转成文字。

仓库不包含任何 API 密钥、字体、音乐、模型权重、演示素材或生成后的视频。

## 环境要求

- Python 3.11 或 3.12（需要时 uv 可以自动安装兼容版本）
- [uv](https://docs.astral.sh/uv/getting-started/installation/)
- 系统 `PATH` 中可调用 [FFmpeg](https://ffmpeg.org/download.html) 提供的
  `ffmpeg` 和 `ffprobe`

macOS 使用 Homebrew 安装：

```bash
brew install uv ffmpeg
```

Debian 或 Ubuntu（uv 使用
[官方安装脚本](https://docs.astral.sh/uv/getting-started/installation/)）：

```bash
sudo apt-get update
sudo apt-get install ffmpeg
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Windows 可以使用 `winget install --id=astral-sh.uv -e` 安装 uv，并从
[FFmpeg 官方下载页面](https://ffmpeg.org/download.html) 选择适用于 Windows 的
构建版本。下载后解压，将其中的 `bin` 目录加入用户或系统 `PATH`，重新打开终端，
再执行下面的验证命令。

继续之前，先确认这些命令可以正常执行：

```bash
uv --version
ffmpeg -version
ffprobe -version
```

## 快速开始

先克隆仓库，后续命令都在项目目录中执行：

```bash
git clone https://github.com/soloshow-labs/ai-vocab-video-generator.git
cd ai-vocab-video-generator
```

### 1. 安装锁定版本的依赖

根据是否需要“语音输入主题”功能，二选一执行，不需要先后运行两条命令：

```bash
# 普通安装（不使用语音输入）
uv sync --frozen

# 安装并启用可选的本地 ASR 语音转写
uv sync --frozen --extra asr
```

两条命令都适用于第一次安装，会在需要时创建 `.venv`，并严格按照 `uv.lock`
安装已锁定的依赖版本。`--extra asr` 会额外安装体积较大的本地语音转写依赖；
`--frozen` 表示不允许 uv 改写锁文件。只有在主动修改项目依赖、需要检查或更新
锁文件时，才使用不带 `--frozen` 的 `uv sync`。

### 2. 可选：创建本地 `.env`

复制 `.env.example` 并不是启动项目的必选步骤。macOS 或 Linux：

```bash
cp .env.example .env
chmod 600 .env
```

Windows PowerShell：

```powershell
Copy-Item .env.example .env
```

- 如果只打算在当前 WebUI 会话中输入密钥、手工粘贴词表，或者使用本地 Ollama，
  可以不创建 `.env`。
- 如果希望应用重启后仍能自动读取密钥，就创建 `.env`，只填写实际使用的服务商，
  其他变量保持为空。
- `.env` 已被 Git 忽略。不要把真实密钥写入 README、源代码、任务脚本或
  `config.toml`，也不要提交到 Git。

### 3. 启动 WebUI

macOS 或 Linux：

```bash
./webui.sh
```

Windows：

```bat
webui.bat
```

启动脚本会自动定位项目目录，并使用锁定的依赖环境。如需更换端口，可以执行：

```bash
./webui.sh --server.port 8503
```

不使用启动脚本时，等效命令是：

```bash
uv run --frozen streamlit run --server.address 127.0.0.1 src/ai_vocab_video_generator/webui.py
```

如果浏览器没有自动打开，请访问 <http://localhost:8501>。在终端按 `Ctrl+C`
可以停止服务。

项目自带的启动脚本和 Streamlit 配置只监听 `127.0.0.1`。这是一个面向单个本机
用户的应用，不包含内置身份认证。不要直接把它暴露到局域网或公网；
如果确实需要远程访问，必须在前面增加经过身份认证的反向代理，并为每个用户隔离
存储目录和凭据。

界面支持 `zh-CN` 和 `en-US`，启动时默认为简体中文。通过页面顶部的语言选择器
即可切换，已保存的素材和渲染设置不会受到影响。

### 4. 生成第一个视频

即使没有大模型密钥和图片搜索 API 密钥，也可以生成视频：

1. 手工填写单词信息。启用 **手动音标**，粘贴重复的三行词组：

   ```text
   苹果
   apple
   /ˈæpəl/
   香蕉
   banana
   /bəˈnɑːnə/
   ```

   也可以同时关闭自动音标和手动音标，只填写重复的“中文 + 英文”两行词组。
2. 上传背景图。每个视频都必须提供一张背景图。
3. 关闭 **启用图片素材**；或者选择本地素材并上传自己有权使用的图片或视频。
   这样不需要 Pexels 或 Pixabay 密钥。
4. 点击 **生成视频**，完成后预览或下载 MP4。

Edge TTS 仍然需要网络连接。输出文件和上传文件保存在已被 Git 忽略的
`storage/` 目录中。

如果要让 AI 根据主题生成单词信息，只需选择一家大模型服务商，填写对应密钥、
主题和单词数量，再点击 **使用 AI 根据主题生成单词信息**。背景图仍然是必填项。

## 按使用场景选择配置

| 目标 | 必须配置 | 不需要配置 |
| --- | --- | --- |
| 粘贴完整的手工词表 | 背景图；手动音标使用三行词组，或关闭两种音标后使用两行词组 | 大模型密钥 |
| 根据主题生成单词信息 | 一家大模型及其密钥，或者已经运行的本地 Ollama 模型 | 其他所有大模型的密钥 |
| 自动补全缺少的音标 | 启用自动音标，并配置当前大模型 | 手动音标 |
| 使用本地单词图片或视频 | 启用图片素材、选择本地来源、上传素材 | Pexels/Pixabay 密钥 |
| 搜索远程静态图片 | 启用图片素材、选择远程来源、配置所选 Pexels 或 Pixabay 密钥 | 本地素材上传 |
| 在本机运行大模型 | 安装并启动 Ollama，拉取 `qwen3.5:9b` | 云端大模型密钥 |
| 用说话代替键盘输入主题 | 执行 `uv sync --frozen --extra asr`，并允许首次下载 SenseVoiceSmall | 普通键盘输入不需要 ASR 扩展 |
| 添加音乐或自定义字体 | 上传有权使用的音乐，或填写本地字体路径 | 正常生成时两者都不是必需项 |
| 重新生成以前的结果 | 对应的 32 位任务 ID；只为需要更换的词条上传替换素材 | 原始浏览器上传路径 |

## 服务商和密钥配置

界面密码框中的密钥只在当前 Streamlit 会话有效。如果希望应用重启后自动读取
密钥，请把 `.env.example` 复制为 `.env`，并只填写实际使用的服务商：

```dotenv
AIVVG_OPENAI_API_KEY=
AIVVG_DEEPSEEK_API_KEY=
AIVVG_MOONSHOT_API_KEY=
AIVVG_QWEN_API_KEY=
AIVVG_CUSTOM_API_KEY=
AIVVG_PEXELS_API_KEY=
AIVVG_PIXABAY_API_KEY=
```

| 变量 | 什么时候需要 | 申请地址 |
| --- | --- | --- |
| `AIVVG_OPENAI_API_KEY` | 使用 OpenAI 生成单词信息或自动补全音标 | [OpenAI API 密钥](https://platform.openai.com/api-keys) |
| `AIVVG_DEEPSEEK_API_KEY` | 选择 DeepSeek 时 | [DeepSeek API 密钥](https://platform.deepseek.com/api_keys) |
| `AIVVG_MOONSHOT_API_KEY` | 选择 Moonshot 时 | [Kimi API 平台](https://platform.kimi.com/console/api-keys) |
| `AIVVG_QWEN_API_KEY` | 选择 Qwen 时 | [阿里云百炼](https://help.aliyun.com/zh/model-studio/get-api-key) |
| `AIVVG_CUSTOM_API_KEY` | 使用自定义 OpenAI 兼容端点时 | 所用服务商的后台 |
| `AIVVG_PEXELS_API_KEY` | 远程图片素材使用 Pexels 时 | [Pexels API](https://www.pexels.com/api/) |
| `AIVVG_PIXABAY_API_KEY` | 远程图片素材使用 Pixabay 时 | [Pixabay API](https://pixabay.com/api/docs/) |

当前会话中，界面输入的密钥优先于对应的 `.env` 值。这些密钥不会写入 `.env`、
`config.toml`、任务清单或生成文件，并会在会话结束后消失。操作系统直接设置的
环境变量优先于 `.env` 中的值。

大模型预设及启动默认值如下：

| 服务商 | 接口地址 | 默认模型 | 说明 |
| --- | --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | `gpt-5.6-terra` | 需要云端密钥 |
| DeepSeek | `https://api.deepseek.com` | `deepseek-v4-flash` | 需要云端密钥 |
| Moonshot | `https://api.moonshot.cn/v1` | `kimi-k2.6` | 需要云端密钥；结构化任务关闭思考模式 |
| Qwen | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen3.7-flash` | 需要云端密钥 |
| Ollama | `http://localhost:11434/v1` | `qwen3.5:9b` | 默认本地安装通常不需要密钥 |
| 自定义 | 用户填写 | 用户填写 | 兼容 OpenAI 的 HTTPS 端点；允许本机回环 HTTP |

使用 Ollama 时，先从[官方网站](https://ollama.com/download)安装，然后准备默认模型：

```bash
ollama pull qwen3.5:9b
```

如果 Ollama 尚未运行，请先启动它；然后在 WebUI 选择 **Ollama** 并保留默认本地
地址。这个项目不会自动下载 Ollama 模型。

## 保存非敏感默认配置

`.env` 用来保存密钥，`config.toml` 用来保存本机的非敏感默认配置。只有内置默认值
不适合自己的使用习惯时，才需要创建 `config.toml`：

```bash
cp config.example.toml config.toml
```

| 配置项 | 作用 | 什么时候需要修改 |
| --- | --- | --- |
| `app.storage_dir` | 保存任务清单、上传文件副本、缓存和生成的 MP4 | 希望把输出放到其他本地磁盘或目录时 |
| `app.model_cache_dir` | 保存可选的 FunASR/SenseVoiceSmall 模型缓存 | 启用语音输入，或希望把模型放到其他磁盘时 |
| `app.font_path` | 为文字样式控件提供初始字体路径 | 系统回退字体无法稳定显示中文时 |
| `llm.preset` | 决定启动时默认显示的大模型服务商 | 平时主要使用的不是 OpenAI 时 |
| `llm.base_url` | 提供启动时的 OpenAI 兼容接口地址 | 使用代理、自定义服务或非默认端点时 |
| `llm.model` | 提供启动时的模型 ID | 账户授权的是其他模型时 |

不要把 API 密钥写入 `config.toml`。当前 WebUI 中的值优先于这些启动默认值。
任务会保存重新生成所需的渲染参数，但永远不会保存服务商密钥。

## WebUI 各组配置的作用

| 配置组 | 主要内容 | 什么时候需要修改 |
| --- | --- | --- |
| 基础设置 | 界面语言；大模型服务商、密钥、地址、模型；远程图片服务商和密钥 | 只修改实际会使用的服务商。通常不需要改预设的地址和模型。 |
| 单词内容 | 主题、单词数量、AI 生成、语音输入、音标模式、可编辑词表 | 每次都应检查最终词表。只有语音输入需要额外安装 ASR。 |
| 画面与素材 | 9:16/16:9、必填背景图、图片素材开关、本地/远程来源 | 每个新视频都要选择比例和背景图；纯文字卡片可关闭图片素材。 |
| 课程流程 | 问题片段、问题文字和样式、问题朗读、倒计时进度条 | 需要“先提问、再揭晓答案”时启用。进度条和问题朗读只在问题片段开启时生效。 |
| 朗读设置 | 中文、英文快读、英文慢读的开关、次数、音色、语速和音量 | 默认仅启用英文快读并朗读一次；需要时再开启其他朗读。关闭开关或把次数设为 0 都不会生成对应音频。 |
| 视觉样式 | 英文/音标/中文的字体、字号、填充色、描边和位置；素材分配、候选数量、尺寸、遮罩、填充和位置 | 适配品牌或版式时修改。位置 `-1` 表示自动居中；`cover` 裁切填满，`contain` 完整显示，`stretch` 可能拉伸变形。 |
| 音频与输出 | 本地背景音乐、音乐音量、朗读压低、输出 FPS | 只添加有权使用的音乐。提高 FPS 会让运动更顺滑，也会增加渲染耗时和文件大小。 |
| 重新生成已有任务 | 输入任务 ID 加载词表，按单词选择替换素材（可选） | 修改已保存任务时使用；之前生成的 MP4 都会保留。 |

自定义大模型端点必须使用 HTTPS；本机回环地址可以使用 HTTP。不同服务商的凭据
彼此独立，自定义端点的凭据还会按 HTTPS 来源（Origin）隔离。URL 片段会被拒绝，查询
参数只允许非敏感的 `api-version`。所有认证信息都应填写在 API 密钥字段中。
Pexels 和 Pixabay 只提供静态图片，不提供视频或音乐。

## 词表格式

自动音标模式使用重复的两行词组：

```text
苹果
apple
香蕉
banana
```

手动音标模式使用重复的三行词组：

```text
苹果
apple
/ˈæpəl/
```

空行会被忽略。手动模式永远不需要 LLM。在自动模式下，如果编辑后的词表缺少
音标，程序会使用已配置的兼容 LLM，只补全音标字段；如果响应修改了已经输入的
中文或英文，程序会拒绝该响应。

## 高级布局和朗读

WebUI 新建视频的竖屏画布固定为 1080×1920，横屏画布固定为 1920×1080。
问题、素材、进度条、英文、音标和中文元素均可设置上、下、左、右偏移。输入
`-1` 表示自动居中；只设置一侧时，元素会贴近该侧；同时设置相对的两侧时，元素
会在剩余区域内居中。

问题片段会先播放项目自有并随安装包提供的倒计时提示音，再播放问题朗读；进度条
会按照两段音频合并后的实际时长播放。答案朗读顺序固定为中文、英文快读、英文
慢读，并会完成各自设置的重复次数。关闭开关或把重复次数设为 0，都不会生成对应
音频。因此，中文和英文慢读默认关闭且重复次数为 0，英文快读默认开启并朗读一次。
内置 Edge TTS 音色目录包含更新时服务返回的全部 14 个中文音色和 47 个英文音色；
已有任务使用的其他音色仍可正常加载。问题朗读拥有独立的开关、重复次数、音色、
语速、音量和试听，不会复用英文快读设置；默认重复一次，并使用默认的英文快读
音色。

Edge TTS 遇到临时断连、超时、服务繁忙或未返回音频时，会自动重试最多两次
（共三次尝试，重试前分别等待 1 秒和 2 秒）。参数、证书和文件保存错误不会自动
重试。如果最终仍失败，界面会用当前语言说明失败的单词序号、朗读类型、原因和
尝试次数；问题片段与试听也会标明对应的朗读类型。自动重试不能替代正常的网络
连接，持续失败时仍需检查网络或朗读设置。

### 支持的本地素材和渲染默认值

所有上传文件都会在使用前解码。仅有匹配的文件扩展名并不能让无效文件通过验证。
本地背景图和单词图片不能超过 32 MiB，远程图片下载仍限制为 10 MiB；所有图片
解码后不能超过 5000 万像素。本地视频不能超过 128 MiB、
5 分钟、单边 3840 像素和 60 FPS；音频上传不能超过 32 MiB；一次生成的视频
时间线最长为 1 小时。

背景图片上传框显示 32 MB 上限；图片和视频共用的上传框显示 128 MB，
但图片仍按 32 MiB 校验，旁边会标明两种限制。界面的 MB 标签由上传组件提供，
实际按 MiB（1 MiB = 1024×1024 字节）计算。大小上限同样适用于预览和重新生成。

| 输入 | 支持的类型 | 说明 |
| --- | --- | --- |
| 背景图 | `.png`、`.jpg`、`.jpeg`、`.webp` | 必填；会复制到任务目录中。 |
| 本地单词素材 | `.png`、`.jpg`、`.jpeg`、`.webp`、`.mp4`、`.mov`、`.m4v`、`.webm` | 可以混用图片和视频；视频原声不会进入成片。 |
| 背景音乐 | `.mp3`、`.wav`、`.m4a`、`.aac`、`.ogg` | 可选，只能由用户提供。 |
| 重新生成时的替换素材 | 与本地素材相同的图片和视频类型 | 先加载任务，再为每个替换文件选择不同的单词。 |

Pexels 和 Pixabay 只提供静态图片，不提供视频或音乐。本地视频会根据卡片片段
时长循环或截断，从一个确定且已保存的偏移位置开始播放，并且始终移除源视频音频。

当前没有接入 Unsplash。它的 API 要求记录下载事件，并展示摄影师和 Unsplash
署名；只有在预览、任务和导出结果都能携带这些署名时才应接入。详情参见
[Unsplash 官方 API 指南](https://help.unsplash.com/en/articles/2511245-unsplash-api-guidelines)。

输出帧率可以设置为 12–60 FPS，默认是 24 FPS。WebUI 新建视频的竖屏固定为
1080×1920，横屏固定为 1920×1080。素材会先应用以下一种适配模式，然后再应用遮罩：

- `contain` 保持宽高比并显示完整素材，素材框中未使用的区域会留空；
- `cover` 保持宽高比并裁切超出部分以填满素材框，这是默认模式；
- `stretch` 不保持宽高比，直接拉伸到完整宽度和高度。

矩形和圆形遮罩在预览和最终输出中使用相同的适配像素。视频素材只在遮罩框内部
运动，卡片文字和进度图层始终位于视频素材上方。

### 背景音乐与朗读时自动降音量

背景音乐默认关闭。启用时，默认音量为 12%，默认朗读压低比例为 65%。选择的
本地音乐会在整个输出视频中连续循环。倒计时、问题朗读或答案朗读期间，音乐增益
会乘以 `1 - ducking_percent / 100`，并在语音边界使用短暂的平滑过渡。例如，
压低比例为 50% 时，语音播放期间的音乐音量是已设置音乐音量的一半。应用不会
搜索或下载音乐。

## 逐词选图

使用 Pexels 或 Pixabay 时，请先解析至少一个词条，并填写所选服务商的当前会话
密钥。展开 **逐词选图（可选）**，通过下拉框或 **上一词 / 下一词** 切换单词，
再点击 **搜索候选**。默认最多展示 **8 张候选图片**，可在 **画面样式 → 图片素材设置
→ 远程候选数量** 中调整为 1–20 张。只搜索当前单词，并优先加载缩略图。
该区域默认收起，收起后不会丢失已选素材。不需要手动选图时，可以直接生成，
程序会自动分配素材。

区域顶部的简要总览会标出每个单词的素材状态：本地上传、手动选图、已自动选图、
已保存素材、搜索无结果或待自动搜索。点击单词即可跳转到对应的选图区，不会改变
已选图片。「待自动搜索」是正常状态，无需逐个检查也可以直接生成；搜索无结果时，
仍然可以为该单词上传自己的素材。

**搜图关键词** 默认使用当前英文单词。如果结果不符合词义，可以换成更具体的词组，
例如把 `bank` 的关键词改成 `river bank`；留空则使用原单词。它只影响图片搜索，
不会修改单词、字幕或朗读。每个词的关键词独立保存，生成后也会写入任务，供后续
重新生成使用。修改关键词后点击 **搜索候选**；已有选图或本地上传会保留，只有
点击 **使用此图** 才会替换它。未选定素材时，正式生成会使用当前关键词自动搜图。

首次搜索会按当前的顺序或随机分配方式选中一张图。点击 **使用此图** 即可更换，
选中的图片会显示蓝色边框，并下载用于生成的完整图片。切换单词不会丢失选择。
**重新搜索** 只更新当前单词的候选列表，不改变已选素材或任务随机种子；搜索结果
可能与之前相同。

调整素材的尺寸、位置、形状和填充方式，不会清空已选图片。临时关闭图片素材，
或切换到本地素材后再切回来，也会保留之前的远程选择。修改单词、服务商、候选数量、
输出比例或分配方式等搜索配置时，会重置对应的远程选图；仅修改搜图关键词不会。
上传、移除替换素材或调整画面设置后，过期的卡片预览会
清除，点击 **预览** 即可查看新效果。

候选都不合适时，可以直接在下方上传本地图片或视频，只替换当前单词的素材；
再次选用候选图片，就会切回远程素材。搜索或下载失败时会保留之前的选择。
未操作的单词仍在生成时自动搜索；搜不到图片时，可以自行上传，也可以保留默认的
中性占位图。

选中的文件会原样复制到任务中，重新生成时直接复用。选图记录属于当前会话，
不是参数预设；生成后保留任务目录即可保留对应素材。

预览缓存是当前会话在本地生成的临时文件，保存在已被 Git 忽略的目录中，不属于
源代码发行包，会话结束后可以删除。

## 单词卡片预览

在生成按钮上方选择 **预览单词** 和 **卡片类型**，再点击 **预览**，即可检查任意
单词的静态排版。默认显示答案卡；启用问题片段后，也可切换到问题卡。关闭问题片段
时，预览会自动切回答案卡。这些选择只控制预览，不会减少最终视频中的单词。

预览使用该单词已经选好的远程图片或本地替换素材。本地批量素材按正式生成时相同的
顺序／随机分配规则选取；视频素材按同一随机种子和单词序号截取一帧。尚未选定远程
素材时显示带提示的占位图，不会自动发起远程搜索。

切换单词、卡片类型或修改相关样式后，旧预览会清除，需再次点击 **预览**。预览保持
小尺寸显示，不生成音频，也不模拟动态进度条；声音和动态效果以生成的视频为准。

## 任务存储与清单

`GenerationRequest` 统一校验词表、布局、FPS、素材类型与适配方式、朗读、音乐和
固定预览素材。`JobStorage` 会把上传内容复制到隔离的任务目录，并写入任务清单。
生成流水线负责协调服务商、语音、Pillow 卡片图层和 MoviePy/FFmpeg 合成；
Streamlit 只负责界面展示。远程服务商适配器会在严格的大小限制内流式读取 HTTPS
响应，拒绝跳转到非 HTTPS URL，并在保存文件前验证内容类型、尺寸和图片解码结果。
当前会话的密钥永远不会持久化。

项目只支持任务清单 Schema v3。早期或未知 Schema 的任务会被直接拒绝，其任务
清单和生成文件不会被修改。Schema v3 任务可以通过任务 ID 和已保存的输入重新生成。

## 重新生成

生成成功后，结果区会显示小尺寸的视频预览、下载按钮和可复制的 32 位任务 ID。
下载文件名包含任务 ID 和视频版本。请同时保留任务 ID 和 `storage/` 中对应的任务
文件夹；只有 ID 无法恢复已删除的任务。

需要修改已保存的视频时：

1. 展开 **重新生成已有任务**，从 **最近任务** 中选择后即可加载；也可以手动输入
   任务 ID，再点击 **加载任务**。
2. 确认加载出的词表。这里使用该任务保存的单词和参数，不会读取或覆盖主编辑区的内容。
3. 按需上传替换图片或视频，再从下拉框中为每个文件选择对应的单词。
   多个文件不能替换同一个单词。原任务未启用图片素材时，不显示替换上传控件。
4. 点击 **替换素材并重新生成**。成功后，结果区会立即显示新版视频并提供下载。
   不上传替换文件也可以重新生成。

修改任务 ID 后，需要重新点击 **加载任务**。ID 填错或加载失败不会改变当前编辑的单词，
也不会删除已保存的任务文件；加载有效任务前，重新生成按钮不可用。
每次重新生成成功都会新增编号文件，例如 `video-0002.mp4`、`video-0003.mp4`，
之前的视频仍保留在任务目录中。

**最近任务** 按最近更新时间显示最多 20 个可用任务，包含主题（或单词）、已保存的
单词数、状态、更新时间和简短 ID。在其他页面生成任务后，可以点击 **刷新列表**。
列表之外的任务仍可通过完整 ID 加载。无法读取或格式不受支持的任务不会出现在列表中，
程序也不会导入、修复或删除这些任务。

加载任务后，可在 **历史视频版本** 中选择、预览和下载已保存的视频，默认选择最新版本。
预览大小与首次生成的结果一致，竖屏和横屏均保持小尺寸。切换版本不会回退任务、
更改已保存的素材、覆盖主编辑区，也不会改变最新生成结果。列表只展示任务中登记的
成品视频。所有时间以运行本程序的电脑为准；版本时间是文件修改时间，不是审计记录。

替换成功的素材会保存到任务中，后续重新生成会继续使用，除非你再次替换该单词的素材。
生成失败时，本次新替换不会成为任务的已保存选择，也不会覆盖之前生成成功的视频。

生成前，程序会保存背景图、本地素材、上传的音乐、支持的自定义字体（TTF、TTC、
OTF 或 OTC，上限 64 MiB）以及固定的远程预览素材。如果 LLM Base URL 解码后的
任一部分包含用户信息、凭据赋值或疑似真实密钥的字符串，程序会拒绝该地址。URL
片段和除非敏感 `api-version` 以外的查询参数同样会被拒绝，避免凭据通过 URL
进入任务清单。重新生成只使用任务中已保存的输入，不再依赖原始上传路径或当前
会话的预览目录。替换素材也会先复制到任务目录，再修改缓存或任务清单状态。

任务清单会为每个阶段相关的输入生成指纹。当指纹和产物仍然有效时，词表、素材、
语音和卡片图层可以独立复用。素材获取键只包含服务商/来源选择输入，以及选中本地
来源的 SHA-256；因此改变适配、遮罩、素材框或偏移会保留已经下载的文件，只让
下游卡片和视频叠加失效。合成审计标识覆盖有序的卡片/素材字节、前景音频、时长和
偏移、音乐、渲染设置以及与编码器相关的设置；任务清单还会记录最终 MP4 的
SHA-256。每次重新生成都会再次执行合成。问题声音设置会使问题语音缓存失效；
素材字节、保存的视频偏移、固定素材或替换素材发生变化时，会使受影响的下游产物
失效。每次成功合成都会获得下一个编号的 MP4，永远不会覆盖之前完成的视频。
重新生成替换素材支持的本地图片和视频格式与首次上传相同。

## 快速说明

- 界面默认使用简体中文（`zh-CN`），也可切换为英文（`en-US`）。
- 背景图支持 PNG、JPG/JPEG、WebP；本地单词素材还支持 MP4、MOV、M4V、WebM，
  视频原声不会进入成片。
- 帧率范围为 12–60，默认 24；素材可选择完整显示（`contain`）、裁切填满
  （`cover`，默认）或拉伸（`stretch`），之后再应用圆形或矩形遮罩。
- 背景音乐只能由用户上传，支持 MP3、WAV、M4A、AAC、OGG；可设置音量与朗读
  压低比例。问题朗读有独立的开关、次数、声音、语速、音量和试听。
- 远程素材支持逐词浏览候选、手动选图和本地覆盖；已选文件会保存到任务中，未操作的词条
  仍在生成时自动搜索。
- 每次成功重新生成都会保留旧 MP4 并新增编号文件；请妥善保存 32 位任务 ID。

## 可选语音输入

语音转写的机器学习依赖体积较大，因此默认环境不会安装。如果最初执行的是普通
安装命令，之后希望启用语音输入，再执行一次以下命令即可：

```bash
uv sync --frozen --extra asr
```

首次安装也可以直接执行这条命令，无需先执行普通的 `uv sync --frozen`。以后重新
同步环境时请继续带上 `--extra asr`，以免可选 ASR 依赖被移除。

第一次转写会把 SenseVoiceSmall 及其配套的 `fsmn-vad` 模型下载到已被 Git 忽略的
`model_cache/` 目录。重新分发这些模型前，请检查各模型自身的许可证和使用条款。

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 提示 `uv: command not found` | 按 uv 官方安装页面完成安装，重新打开终端，再执行 `uv --version`。 |
| 找不到 FFmpeg 或 `ffprobe` | 安装 FFmpeg，并在同一个终端确认 `ffmpeg -version` 和 `ffprobe -version` 都能执行。 |
| 8501 端口已被占用 | 执行 `./webui.sh --server.port 8503`，然后打开终端中显示的新地址。 |
| API 返回 401 或 403 | 确认当前选择的服务商和密钥属于同一家；界面中非空的密钥会在当前会话覆盖 `.env`。 |
| 无法连接 Ollama | 启动 Ollama，执行 `ollama list`；如果没有界面填写的准确模型名称，就先拉取该模型。 |
| Edge TTS 或远程图片超时 | 检查所选服务的网络连接后重试；改用本地素材可以避免图片服务请求，但朗读仍会使用 Edge TTS。 |
| 语音转文字不可用 | 执行 `uv sync --frozen --extra asr`，重启应用，并等待第一次模型下载完成。 |

终端通常会提供最有用的诊断信息。生成任务和日志位于配置的 `storage_dir` 下；
面向用户的错误提示和任务清单都会隐藏凭据信息。

## 字体与素材授权

渲染器会优先尝试系统中常见的中日韩（CJK）字体，否则回退到 Pillow 默认字体。
如果需要一致的中文排版，请配置已经安装且采用 OFL 许可证的字体，例如
Noto Sans CJK。
字体通过本地路径引用，会保存到每个任务中供重新生成使用，永远不会复制到源代码
仓库。

你需要自行确认，自己有权使用和编辑以下内容，也有权将其与音频同步、发布或重新
分发：上传的背景图、本地图片或视频素材、音乐、字体，以及通过第三方服务商获取
的素材。
能够从服务商获取素材，并不代表已经获得使用授权。仓库不捆绑任何字体、音乐、
演示素材或服务商下载文件。
